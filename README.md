# Supply Chain Analytics Dashboard

## Project Overview
This project focuses on analyzing supply chain operations through interactive dashboards and data analysis techniques. The project identifies sales trends, shipping delays, customer segments, and regional profitability using SQL, Python, and Power BI.

## Tools Used
- SQL
- Python
- Pandas
- Power BI

## Key Insights
- Europe market generated highest sales
- Standard Class had highest delivery time
- Consumer segment generated highest revenue

## Dashboard Features
- Sales Analysis
- Delivery Analysis
- Profit Analysis
- Executive Overview
